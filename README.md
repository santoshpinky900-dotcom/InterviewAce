🎤 InterviewAce

InterviewAce is an AI-powered interview preparation web application built using Python and Streamlit.

It helps users prepare for technical and HR interviews through quizzes, mock interview questions, answer evaluation, resume analysis, and interview reports.

✨ Features

- 🔐 User Registration and Login
- 🎯 Career-based Interview Preparation
- 📚 Beginner, Intermediate, and Advanced Difficulty Levels
- 📝 Interview Quiz
- 🎤 Mock Interview Questions
- 🤖 AI-based Answer Evaluation and Feedback
- 📄 Resume Analysis
- 📊 Skill Analysis
- 📑 Interview Report Generation
- 💾 SQLite Database

🛠️ Technologies Used

- Python
- Streamlit
- SQLite
- Git & GitHub
- PDF Report Generation

👨‍💻 Career Paths

Currently, InterviewAce supports:

- Data Analyst
- Python Developer
- Java Developer
- Web Developer
- HR Interview

▶️ How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Install the required Python packages.
4. Run the Streamlit application.

streamlit run app.py

5. Open the local URL shown in the terminal.
